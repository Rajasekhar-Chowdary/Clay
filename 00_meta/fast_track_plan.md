# Fast-Track Plan — Learn Clay (Beginner→Advanced) WHILE Building Portfolio

Built 2026-06-10. Account: **live with credits**. Budget: ~5–7 hrs/week.

## The principle (why this works)
Accelerated-learning's **directness** rule: you don't study Clay, you build the real thing.
Every phase below ends in a **portfolio artifact** — the artifact IS the exam. If you can ship
it with a coverage number, you've passed the phase. No passive reading, no tutorial limbo.

Method baked in every session: **build the real thing → measure coverage → 3 Anki cards →
log the number in `progress_tracker.md`.** Ship public proof (LinkedIn/GitHub) at each ★.

## The 6-week sprint (each week = one focused build)

| Wk | Learn (curriculum file) | Build (the real thing) | Portfolio artifact | Coverage gate |
|----|-------------------------|------------------------|--------------------|---------------|
| 1 | 01_beginner 01–03 | 25-row email waterfall (Apollo→Hunter→stop) | Screenshot + coverage note | ≥70% |
| 2 | 01_beginner 04 + 02_intermediate 01–02 | 4-provider waterfall + company enrichment on same 25 | `07_portfolio/01_clay_enrichment_pipeline` README w/ real metrics ★ | ≥85% |
| 3 | 02_intermediate 03–04 | Claygent: LinkedIn post hook + 100-row run | Claygent prompt library entry + 100-row case study ★ | ≥85% @ 100 rows |
| 4 | 03_advanced 01–02 | Signal detect (job posting / funding) on a target list | `07_portfolio/02_signal_triggered_system` w/ real personalize.py output ★ | n/a (signal precision) |
| 5 | 03_advanced 03–04 + 04_expert 01 | Clay→n8n→Supabase/HubSpot wire-up + Clay API row-add | n8n workflow JSON + Clay API script working | <5 min lead→CRM |
| 6 | 04_expert 02–04 + 06_scenarios | Pick 1 competition scenario end-to-end + CRM audit on real export | `07_portfolio/03_crm_audit` w/ real HubSpot scorecard ★★ | publish all 3 ★ |

★ = recruiter-facing proof to publish. ★★ = the differentiator (run crm_audit.py on real CRM data).

## Resume-reality close-out
By end of Wk 6, the 3 portfolio projects your resume already claims are REAL with metrics +
public links. That's the actual win condition, not "finished the curriculum."
